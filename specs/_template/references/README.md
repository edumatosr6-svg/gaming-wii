# <Slug> — Referências

Documentos e padrões externos que as specs precisam respeitar. O `spec-generator` lê o
que estiver nesta pasta e trata o conteúdo como restrição, não como sugestão.

Coloque aqui: links de especificação de APIs usadas, padrões de protocolo, documentação
de bibliotecas obrigatórias, guias de estilo ou normas que o produto precisa seguir.

Não coloque aqui o que é intenção do produto — isso vive em `descriptions.md`.
